# RuangBK - Student Counseling Platform

RuangBK is a web-based counseling system designed to help students easily communicate with school counselors in a safe, structured, and modern digital environment.

The platform supports online counseling booking, real-time chat, mental health assessments, mood tracking, and educational articles.

## Features

### Student Features
- Online counseling booking system
- Real-time chat with school counselors (WebSocket)
- Mental health test & result tracking
- Daily mood check
- Access to mental health articles
- Counseling history tracking

### Teacher (Counselor) Features
- Manage counseling requests
- Accept / reject booking sessions
- Real-time chat with students
- View student counseling history

### Admin Features
- User management (students & teachers)
- Role-based access control
- Article management system
- Full system control dashboard

---

## Tech Stack

- **Backend:** Laravel 12 (PHP 8.3)
- **Frontend:** Blade Templates + Tailwind CSS
- **Database:** MySQL
- **Real-time Communication:** Laravel Reverb (WebSocket)
- **Authentication:** Laravel Breeze
- **Authorization:** Spatie Laravel Permission
- **Build Tool:** Vite
- **Deployment:** Railway
